# About Elene Pitskhelauri

A simple Python console app that presents information about **Elene Pitskhelauri** and can automatically generate a `README.md` file in Markdown format.

The project is based on a structured Python dictionary containing profile details such as education, experience, projects, skills, languages, and highlights. It provides a menu-driven interface in the terminal and includes an option to export the same information into a README file.  [oai_citation:1‡GitHub](https://github.com/elenepitskhelauri/about_elene_pitskhelauri/raw/refs/heads/main/about_elene.py)

## Features

- View profile information in a console menu
- Show education, experience, projects, skills, languages, and highlights
- Export all information into a `README.md` file
- Simple Python-only project with no external dependencies  [oai_citation:2‡GitHub](https://github.com/elenepitskhelauri/about_elene_pitskhelauri/raw/refs/heads/main/about_elene.py)
